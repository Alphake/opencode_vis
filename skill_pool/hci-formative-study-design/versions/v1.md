## 使用场景

When user needs to design a user study for HCI research, conduct developer interviews, create formative study methodology, or write CHI paper methodology sections.

## 工作流程

- Clarify research goals and target user population (e.g., developers using coding agents)
- Review CHI methodology contribution requirements (Context → Content → Contribution framework)
- Identify relevant existing research and pain points in the domain
- Define specific research questions (RQ1, RQ2, RQ3 format)
- Design participant recruitment strategy with clear inclusion/exclusion criteria
- Segment participants into meaningful groups (e.g., non-users, churners, adopters)
- Create screening questionnaire to identify suitable participants
- Design semi-structured interview protocol using 5E framework (Engage, Explore, Explain, Elaborate, Evaluate)
- Balance open-ended questions (for exploration) with closed questions (for validation)
- Structure interview flow: background (5min) → theme exploration (40min) → deep probing (10min) → summary (5min)
- Align methodology section with CHI contribution requirements for replicability and value demonstration

## 注意事项

When user has a complete formative study design including research questions, participant plan, and interview protocol ready for IRB/ethics review and execution.
