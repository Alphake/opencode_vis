## 项目规划讨论 - opencode harness 平台

**用户目标**：为 opencode 搭建一个 harness 监控平台，展示 agent 运行状态，配合导师的可视化研究需求（用 D3）。

**项目当前状态（已完成）**：
- Plugin（TypeScript/Bun）：捕获所有 session/message/tool 事件，已运行
- Backend（Flask + SQLite）：REST API + SSE 实时推送，完整可用
- Frontend（React + Vite）：三栏布局、AgentTree、OverviewPanel（d3-contour KDE）、AgentStatsPanel 已有

**目标 UI**（下周一演示 deadline）：
- 左侧：对话面板（类 opencode 终端界面，有输入框）
- 右侧：监控面板，每个 Todo 任务一个卡片，卡片内用 D3 渲染 event flow（tool call 序列图）
- 左右映射：Todo 卡片与消息流高亮联动

**关键技术决策**：
1. **继续在现有仓库开发**，不新建仓库，Plugin 无需剥离（已独立）
2. **左侧对话面板**：MVP 阶段做只读消息展示（Phase C），之后考虑 iframe 嵌 opencode --web
3. **prompt 改造**：通过 opencode.json 的 instructions 字段让 agent 每次先生成 Todo 计划
4. **D3 可视化重点**：TodoFlowPanel - 每个 Todo 一个卡片，卡片内为 event sequence 流程图

**4天 MVP 计划**：
- Phase 0（今天）：全链路确认跑通 + opencode.json instructions 配置
- Phase 1（周五）：TodoFlowPanel 组件（D3 事件流图，重点）
- Phase 2（周六）：MessageStreamPanel 消息面板
- Phase 3（周日）：整合 + 打磨 + README

**补充 - 清空数据方法（11:15 确认）**：
- DB 1.5MB + 日志 6.5MB，删除 cockpit.db 三文件 + 清空两个 jsonl 即可
- 内存慢原因：DashScope embedding 网络延迟，不是数据量
- 两个月计划：第1月做功能，第2月重构开源，下周一前不动 embedding 代码

**已有 API 对齐**（无需新开接口，下周一前）：
- `GET /api/todos/:sessionId` → 任务列表
- `GET /api/tools/calls?sessionId=` → 工具调用序列
- `GET /api/sessions/:id/messages` → 消息流
- SSE `/api/events/stream` → 实时推送
